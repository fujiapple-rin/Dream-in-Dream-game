# Dream in Dream

夢だったら起きる。現実だったら眠る。ブラウザだけで遊べる、一人称の間違い探しゲームです。

## 遊ぶ

- パソコン版: https://fujiapple-rin.github.io/Dream-in-Dream-game/
- スマホ版(横画面): https://fujiapple-rin.github.io/Dream-in-Dream-game/mobile.html

インターネットに接続した状態で、ブラウザで開いてください。精神的に重い描写を含みます。

## 操作

- パソコン: 右クリックを押しながらマウスを動かすと見渡せます(矢印キー・A / D でも左右に回れます)。ホイールで拡大します。
- スマホ: 画面をドラッグして見渡します。ズームボタンで拡大します。
- 部屋の様子を覚えたら「眠る」。異変があれば夢(「起きる」)、なければ現実(「眠る」)を選びます。

## ファイル

- `index.html` … パソコン版
- `mobile.html` … スマホ版(横画面)
