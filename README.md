# Dream in Dream

夢だったら起きる。現実だったら眠る。ブラウザだけで遊べる、一人称の間違い探しゲームです。

- `index.html` … パソコン版
- `mobile.html` … スマホ版(横画面)

インターネットに接続した状態で、ブラウザで開いてください。精神的に重い描写を含みます。

## 素材

- 3Dモデル(家具・ビル・木): [Kenney](https://kenney.nl/) の Furniture Kit / City Kit (Commercial) / Nature Kit(CC0)。ライセンス文は `assets/models/` に同梱しています。
- 3Dエンジン: three.js(r128)。
